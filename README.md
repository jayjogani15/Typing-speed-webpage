# 🚀 TypeRush - Speed Typing Test

TypeRush is a modern, fast, and interactive web-based speed typing test. Challenge yourself to improve your typing speed and accuracy with this sleek and responsive application.

## 🌟 Features

- **Real-time Stats:** Track your Words Per Minute (WPM), Accuracy, and Characters Per Minute (CPM) as you type.
- **Dynamic Text Samples:** Each test session provides a different text challenge.
- **Visual Feedback:** Instant highlighting of correct and incorrect characters.
- **Progress Tracking:** Interactive progress bar and smooth scrolling display.
- **Detailed Results:** Get a comprehensive breakdown of your performance at the end of each test.
- **Premium Design:** Features a beautiful glassmorphism UI with vibrant gradients and smooth animations.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Custom styling with modern gradients and responsive layout.
- **JavaScript (Vanilla):** Core logic for timer, calculations, and character processing.

## 🚀 Getting Started

To run this project locally, simply clone the repository or download the files, and open `index.html` in your web browser.

```bash
# Clone the repository
git clone https://github.com/yourusername/typerush.git

# Open the project
cd typerush
open index.html
```
